In BUTT

  1. Open BUTT and select the streaming server tab.
  2. Choose ShoutCast as the server type.
  3. Set the hostname to your ShoutCast server address.
  4. Set the source port and mount point to /WXL20.
  5. Enter the ShoutCast source password provided by your server admin.
  6. Pick MP3 at 128 kbps and click Start Streaming.

About the Network

The North American Weather Radio Network delivers continuous, real-time weather and hazard information for communities throughout the NAFA coverage area, including the United States, Canada, and Mexico.

WXL20

WXL20 is delivered as a ShoutCast-based stream for live broadcast use and public listener access. This setup is designed to work with BUTT and other ShoutCast-compatible encoders.

Emergency Use

Weather radio is one of the most reliable tools for receiving severe weather warnings and emergency information when other communication channels may be disrupted.
