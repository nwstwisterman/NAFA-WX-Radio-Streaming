HLS Overview

HLS is a browser-friendly streaming format that works well for live audio and web playback. FFmpeg turns the microphone input into segments and a playlist, which is then served by Render.

FFmpeg Source

The stream source is generated with FFmpeg from a microphone or local audio input and published to the live HLS folder. This enables browser listeners to connect without needing a dedicated ShoutCast server.

Setup Notes

The live playlist URL should point to the directory that contains the generated HLS playlist file, typically under a /live folder in the Render-hosted app.
